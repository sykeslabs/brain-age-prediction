# Brain Age Prediction

Course project for **ETH 275-0005-00L**: predict a person's age from 832 numeric
brain-derived features per subject. The raw features contain missing values, corrupted
cells, anomalous rows and many irrelevant/redundant columns, so the pipeline handles each
of these explicitly before regression. Predictions are submitted to Kaggle.

## Project structure

```
brain-age-prediction/
├── main.py                  # entry point: runs the full pipeline, writes the submission
├── pipeline/                # one module per pipeline stage
│   ├── split.py             # train / validation split
│   ├── outliers.py          # cell-level outlier correction + row-level outlier removal
│   ├── impute.py            # missing-value imputation (per-column median)
│   ├── feature_selection.py # correlation pruning + top-k F-test selection
│   ├── scale.py             # QuantileTransformer scaling
│   └── regression.py        # model zoo, CV-based selection, stacking, final refit
├── tests/                   # pytest suite, one test_<module>.py per pipeline module
├── data/                    # original competition data (do not modify)
│   ├── X_train.csv          # 1212 rows: id, x0..x831
│   ├── y_train.csv          # 1212 rows: id, y (age)
│   ├── X_test.csv           # 776 rows:  id, x0..x831 (no labels)
│   └── sample.csv           # expected submission format
├── outputs/
│   └── submission.csv       # generated by main.py
├── docs/
│   ├── DOCUMENTATION.md     # plain-language log of every experiment and its numbers
│   └── DEFENSE.md           # 15-minute presentation / defense script
├── requirements.txt
├── pytest.ini
└── CLAUDE.md                # detailed design notes for the pipeline
```

## Setup

Tested with Python 3.13.

```bash
pip install -r requirements.txt
```

## Usage

Run the full pipeline (reads `data/`, writes `outputs/submission.csv`):

```bash
python main.py
```

`main.py` resolves paths relative to its own location, so it can be launched from any
working directory. It prints every candidate model's cross-validated R² (mean ± std),
train R² and validation R², marks the selected model, and writes the submission file.

Run the tests:

```bash
python -m pytest
```

## Pipeline

| # | Stage | Module | What it does |
|---|-------|--------|--------------|
| 0 | Split | `pipeline/split.py` | Holds out 10% of the labelled data as validation before anything is fit. |
| 1 | Cell outliers | `pipeline/outliers.py` | Per-column IQR bounds (k = 2.5, fit on train) turn implausible single values into NaN in train/val/test. |
| 2 | Imputation | `pipeline/impute.py` | Fills NaNs with per-column medians learned on the training fold. |
| 3 | Row outliers | `pipeline/outliers.py` | `IsolationForest` drops anomalous rows from the training fold only. |
| 4 | Feature selection | `pipeline/feature_selection.py` | Removes near-duplicate features (keeping the more target-relevant one), then keeps the top 100 by F-test. |
| 5 | Scaling | `pipeline/scale.py` | `QuantileTransformer` to a normal distribution. |
| 6 | Regression | `pipeline/regression.py` | Ridge, RandomForest, HistGradientBoosting, CatBoost, SVR and Gaussian-process candidates, plus a stacked ensemble; selected by 5-fold CV R² on the training fold, then refit on train + validation. |

Feature selection and scaling run inside each CV fold so the CV estimate doesn't leak
information from held-out rows. The validation split is only used as a diagnostic and,
once the model is chosen, for the final refit. It is never used to choose the model.

For the reasoning and measurements behind each choice, see
[`docs/DOCUMENTATION.md`](docs/DOCUMENTATION.md) and [`CLAUDE.md`](CLAUDE.md).

## Evaluation

`X_test.csv` has no labels, so the only local signals are cross-validated R² and validation
R² (target: validation R² ≥ 0.5). The real test score comes from the Kaggle leaderboard
after uploading `outputs/submission.csv`.
